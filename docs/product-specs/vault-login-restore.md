# `vault-login-restore` — 登录与提示词恢复

**阶段：** S1 | **依赖：** `vault-setup` | **交互类型：** 表单流  
**状态：** 见 `feature_list.json`

## 目标

已初始化保险箱后，支持主密码单步解锁；忘记密码时分步用恢复提示词重置主密码并解锁。

## 用户路径 / 交互细节

1. **密码登录（单步）：** 仅主密码 → 校验成功解锁。
2. **忘记密码（分步）：**
   - 步骤 1：恢复提示词 → 下一步
   - 步骤 2：新主密码 → 下一步
   - 步骤 3：确认新主密码 → 提交恢复并解锁
3. 可返回密码登录；恢复步骤可「上一步」。
4. 解锁成功后的窗口切换由 `login-window-flow` 负责。

## 状态与反馈

| 场景 | 表现 |
|------|------|
| 空态 | 当前步表单 |
| 加载中 | 按钮禁用 |
| 错误 | 本步错误文案；留在认证宽窗 |
| 成功 | 进入主界面 |

## 窗口或界面形态

认证宽窗横向双栏内完成；不显示完整原生菜单。

## 验收清单

- [ ] 正确主密码可解锁
- [ ] 错误主密码有明确错误，不进入主界面
- [ ] 恢复三步完成且确认一致后可解锁
- [ ] 恢复过程不同时同屏展示「新密码 + 确认」两框

## 本功能非目标

- 生物识别 / 记住密码
- 在线找回
