# `login-window-flow` — 登录窗与主窗切换

**阶段：** S2 | **依赖：** `vault-login-restore`, `ui-zh-i18n-ready` | **交互类型：** 窗口流  
**状态：** 见 `feature_list.json`

## 目标

区分「认证窗口」与「主窗口」：未解锁时使用横向宽认证窗（左角色 / 右表单）；密码（或恢复）校验成功后才进入主窗口。设置中「主密码 + 确认密码」同屏展示（确认在主密码下方），校验一致且 ≥8 位后进入助记词步骤；恢复中「新密码 + 确认」仍采用分步引导；首次登录设置密码与确认密码；忘记密码时候利用助记词恢复密码；助记词生成与助记词调整用户体验优化。

## 用户路径 / 交互细节

1. **首次使用（未初始化）— 分步设置**
   - 进入认证宽窗设置流（细节亦见 `vault-setup`）
   - **步骤 1 — 设置主密码：** 同屏展示主密码输入（可显隐）与确认密码输入（可显隐，位于主密码下方）；校验一致且 ≥8 位 → 提交创建 → 进入步骤 2
   - **步骤 2 — 备份恢复提示词：** 生成助记词 → 九宫格展示与调整 → 用户确认已备份 → 进入主窗口
   - 校验失败时停留步骤 1，错误文案在对应输入框下方红色展示

2. **非首次（已初始化且锁定）**
   - 单步：仅输入主密码 → 登录（无需确认步）
   - 校验成功 → 进入主窗口并展示条目列表
   - 密码错误：右侧表单区显示错误文案，不进入主窗口

3. **忘记密码 — 分步恢复**
   - 登录页「忘记密码」进入恢复流
   - **步骤 1 — 恢复提示词：** 输入 12 词 →「下一步」
   - **步骤 2 — 新主密码：** 仅新密码 →「下一步」
   - **步骤 3 — 确认新密码：** 确认一致 → 提交恢复并进入主窗口
   - 可返回密码登录；步骤间可「上一步」

4. **锁定**
   - 主界面锁定 → 回到认证宽窗与登录页（单步密码）

5. **布局与细节**（借鉴趣味登录页，**横向宽认证窗**）

   **窗口尺寸（宽模式，符合桌面登录习惯）**
   - 认证态约 **780×480**（最小约 700×420）；横向为主，便于左角色 + 右表单。
   - 主窗口仍约 **1100×720**；解锁后可变大并显示完整原生菜单。
   - 仍为**单 BrowserWindow** 缩放切换，不新建第二窗。

   **布局（横向双栏）**
   - 采用「**左侧角色区 + 右侧密码/设置区**」，约 1:1，**无圆角、铺满**认证窗内容区。
   - **左侧（角色区）**：灰底（`#e9e9e9` 一类），角色叠加排列；**角色底边与右侧主按钮底边对齐**。
   - 角色高度在约 780 宽窗内约样例的 **50%–65%**（单角色高度约 50–140px），避免溢出。
   - **右侧（表单区）**（日常登录对齐产品 mock）：
     1. **上区居中**：大标题「欢迎回来！」+ 灰色副标题（设置/恢复标题随步骤变化，同样上区居中）
     2. **步骤指示**（仅设置/恢复）：设置为「1 / 2」，恢复为「1 / 3」，当前步高亮
     3. **下划线输入**：仅底边框；密码旁用 **眼睛 icon** 显隐（不用文字「显示/隐藏」）
     4. **选项行**（仅日常登录）：左「记住密码」勾选；右「忘记密码？」链接（进入恢复流）
     5. **主按钮**：近黑（`#111`）全宽 **胶囊**「登录」/「下一步」等；**无** Google / 第三方登录按钮
   - 「记住密码」只持久化勾选偏好（localStorage），**绝不**明文存储主密码。
   - 窄屏（若将来 web 预览 &lt; 720px）可降级为上角色下表单；桌面 Electron 认证窗以横向为准。

   **助记词生成和调整页面样式**
   - 生成助记词：标题「生成助记词」，副标题「请记好助记词」，生成助记词按钮。助记词需要采用九宫格的形式展示所有的助记词，并且可以手动的替换位置，也可以调整每个助记词中的字母顺序，不能改变生成的助记词单词
   - 助记词样式： 每个助记词的样式简洁美观即可
   - 助记词页面icon：可以选择合适的icon搭配

   **分步规则（密码与确认）**
   - **设置：** 密码 + 确认（同屏）→ 提示词备份，两步串行；步骤 1 同屏校验一致性且 ≥8 位。
   - **恢复：** 提示词 → 新密码 → 确认新密码，三步串行。
   - **日常登录：** 单步主密码 + 记住/忘记行 + 黑胶囊登录。
   - 每步校验失败：停留本步，文案错误 + 可选角色惊讶态；不跳步。

   **角色与输入联动（趣味反馈，须克制）**
   - 当前步输入非空：主角色轻倾（`.lean`）；幅度约 ±6°～10°。
   - 处于「密码类」步骤且输入非空：全体窥视 + 眼左偏（`.peeking`）；输入期间可不跟眼。
   - 密码类步骤为空且指针在左栏移动（可选）：瞳孔跟随，位移上限约 4–6px。
   - 本步必填为空仍点主按钮：惊讶嘴 + 轻倾（`.surprised`），并显示文案错误。

   **明确不做**
   - Google / 第三方登录；明文记住主密码。
   - 认证态显示完整原生菜单（文件/编辑/帮助/设置等仍隐藏）。
   - 恢复流中同屏同时展示「新密码 + 确认密码」双输入（恢复仍为分步）。

## 状态与反馈

| 场景 | 表现 |
|------|------|
| 认证态 | 宽窗横向双栏、无完整菜单；设置分步 / 登录单步 / 恢复分步 |
| 主窗口态 | 更大窗、完整菜单；条目主界面 |
| 切换中 | main `setSize` / `center`；界面随 view / 步骤切换 |

## 窗口或界面形态

| 模式 | 尺寸（约） | 菜单 |
|------|------------|------|
| `auth` | **780×480**（宽模式） | 隐藏完整菜单（Win/Linux `null`；macOS 最小应用菜单） |
| `main` | 1100×720 | File / Edit / View / Window / Help / Settings |

单窗口 `setSize` / `center`，不新建第二个 BrowserWindow。Renderer 经 `window.vault.app.setWindowMode`。

## 验收清单

- [ ] 首次：两步「设密+确认（同屏）→ 备份提示词」→ 进入主窗口
- [ ] 再次启动：单步密码解锁 → 进入主窗口
- [ ] 忘记密码：分步「提示词 → 新密码 → 确认」→ 进入主窗口
- [ ] 认证态为横向宽窗（左角色右表单）、无完整原生菜单；解锁后主窗更大且有菜单
- [ ] 锁定后回到认证宽窗登录页
- [ ] 设置中主密码与确认密码同屏展示（确认在主密码下方）；恢复中密码与确认分步

## 本功能非目标

- 多窗口并行（登录窗与主窗各一个进程窗）
- 用户自定义任意窗口尺寸的设置页
- 认证窗内嵌完整 Settings 菜单改语言
