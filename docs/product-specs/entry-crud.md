# `entry-crud` — 密码条目增删改查

**阶段：** S1 | **依赖：** `entry-list` | **交互类型：** 表单流  
**状态：** 见 `feature_list.json`

## 目标

在主界面创建、查看、更新、删除密码条目；字段在本地 SQLite 中加密存储。

## 用户路径 / 交互细节

1. **创建：** 填写标题 / 用户名 / 密码 / 网址 / 备注 → 提交 → 列表刷新。
2. **读取：** 列表中查看；密码默认掩码，可切换显示。
3. **更新：** 选中编辑 → 改表单 → 保存 → 列表刷新。
4. **删除：** 确认后删除 → 列表刷新。

## 状态与反馈

| 场景 | 表现 |
|------|------|
| 空态 | 新建表单可用 |
| 加载中 | 提交时按钮禁用或简要状态 |
| 错误 | 「保存失败」等文案 |
| 成功 | 列表更新；编辑态退出或清空表单 |

## 窗口或界面形态

主窗口内左右/主从布局（列表 + 表单）；不改变窗口模式。

## 验收清单

- [ ] 可创建条目并出现在列表
- [ ] 可编辑并保存变更
- [ ] 可删除条目
- [ ] 密码字段默认可隐藏；经 IPC，renderer 不直连数据库

## 本功能非目标

- 导入/导出文件
- 附件与 TOTP
