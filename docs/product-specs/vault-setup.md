# `vault-setup` — 首次设置主密码与恢复提示词

**阶段：** S1 | **依赖：** （无） | **交互类型：** 表单流（分步）  
**状态：** 见 `feature_list.json`

## 目标

首次启动时创建本地保险箱：分步设置主密码并确认，再生成可备份的恢复提示词。

## 用户路径 / 交互细节

1. 未初始化时进入认证宽窗设置流（布局见 `login-window-flow`）。
2. **步骤 1：** 输入主密码（至少 8 位，可显隐）→「下一步」。
3. **步骤 2：** 输入确认主密码；不一致则留在本步提示，不提交。
4. 确认通过后创建保险箱，进入 **步骤 3：** 展示 BIP39 恢复提示词（12 词，仅此完整展示一次）。
5. 用户确认已备份后，进入主窗口（窗口切换见 `login-window-flow`）。

## 状态与反馈

| 场景 | 表现 |
|------|------|
| 空态 | 当前步单一输入 |
| 加载中 | 创建提交时按钮禁用 |
| 错误 | 本步下方错误文案（不一致 / 过短 / 服务失败） |
| 成功 | 进入提示词备份步，再确认后进主界面 |

## 窗口或界面形态

遵循认证宽窗横向双栏（`login-window-flow`）；右侧为分步表单，左侧角色区。

## 验收清单

- [ ] 未初始化时走设置分步，不同时显示密码+确认两框
- [ ] 密码不足 8 位或两次不一致无法创建
- [ ] 创建成功后展示 12 词提示词，确认后进入已解锁主界面

## 本功能非目标

- 用户自定义短「密码提示」文案
- 跳过提示词备份强制进入
