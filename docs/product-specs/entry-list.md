# `entry-list` — 密码条目列表

**阶段：** S1 | **依赖：** `vault-login-restore` | **交互类型：** 列表流  
**状态：** 见 `feature_list.json`

## 目标

保险箱解锁后，在主界面展示已解密的密码条目列表。

## 用户路径 / 交互细节

1. 进入主窗口后自动请求条目列表。
2. 有数据时展示条目卡片/行（标题、用户名等摘要）。
3. 无数据时展示空态引导（提示右侧或表单区可新建）。
4. 支持刷新列表（创建/更新/删除后同步）。

## 状态与反馈

| 场景 | 表现 |
|------|------|
| 空态 | 「暂无条目」类文案 |
| 加载中 | （可选）加载提示；当前以实现为准 |
| 错误 | 列表区域或顶部错误信息 |
| 成功 | 显示条目数量与列表 |

## 窗口或界面形态

主窗口内；遵循已解锁全局约定。

## 验收清单

- [ ] 解锁后可见列表区域
- [ ] 无条目时有明确空态
- [ ] 有条目时展示可读摘要（不明文长期暴露密码，需显式「显示」）

## 本功能非目标

- 搜索 / 分组 / 拖拽排序（可后续独立功能）
