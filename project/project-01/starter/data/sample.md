Harness Engineering — Knowledge Base

What is a harness?
A harness is the environment, instructions, tools, state, and feedback that surround an AI agent so it can complete real engineering work reliably.

Architecture pattern
The Electron app uses a layered architecture with clear boundaries between the main process, preload scripts, and renderer. Each layer communicates through typed IPC channels.

Document import
Documents are imported by copying the source file to the local data directory. The system extracts text content and creates metadata including title, filename, size, and import timestamp.

Indexing and retrieval
The indexing pipeline splits documents into chunks of approximately 500 characters at paragraph boundaries. Retrieval works by matching query keywords against indexed chunks and returns citations.
